# 支付宝收款监听端（安卓APP）使用说明

## 功能
- 监听支付宝收款通知
- 通过WebSocket实时推送到电脑端
- 电脑端收到后自动播报

## 编译安装

### 方法一：用Android Studio编译（推荐）
1. 下载安装Android Studio
2. 打开本项目目录（alipay_listener_app）
3. 等待Gradle同步完成
4. 连接安卓手机（开启USB调试）
5. 点击Run按钮安装到手机

### 方法二：用命令行编译
```bash
cd alipay_listener_app
./gradlew assembleDebug
# 生成的APK在 app/build/outputs/apk/debug/app-debug.apk
```

## 使用步骤

### 电脑端
1. 打开"智慧收款"软件
2. 软件会自动启动WebSocket服务（端口16888）
3. 查看电脑的IP地址（cmd里输入ipconfig）

### 手机端
1. 安装本APP
2. 确保手机和电脑在同一个WiFi网络
3. 打开APP，填写电脑的IP地址（例如192.168.1.100）
4. 端口默认16888，不用改
5. 点击"保存配置"
6. 点击"开启通知监听权限"，在系统设置中允许本应用监听通知
7. 点击"启动监听服务"
8. 保持支付宝APP在后台运行

### 测试
1. 用另一台手机扫你的支付宝收款码
2. 付款成功后，手机支付宝会收到收款通知
3. APP会自动推送到电脑端
4. 电脑端会语音播报"支付宝收款到账X元"

## 注意事项
1. 手机和电脑必须在同一个局域网
2. 支付宝APP需要在后台运行，不要被系统杀掉
3. 建议把本APP加入电池优化白名单，防止后台被杀
4. 如果连接失败，检查电脑防火墙是否放行端口16888
5. 鸿蒙系统请在手机管家中允许本应用后台运行和通知监听

## 常见问题

### Q: 连接不上电脑？
A: 检查：
- 手机和电脑是否在同一个WiFi
- 电脑IP地址是否正确
- 电脑防火墙是否放行16888端口
- 电脑端"智慧收款"软件是否已打开

### Q: 收到收款但没推送？
A: 检查：
- 通知监听权限是否开启
- 支付宝是否收到了收款通知
- APP是否在后台运行（没有被系统杀掉）
- 查看APP里的运行日志

### Q: 鸿蒙系统能用吗？
A: 可以，鸿蒙系统兼容安卓应用。但需要在手机管家中：
- 允许本应用后台运行
- 关闭电池优化
- 允许通知监听权限
